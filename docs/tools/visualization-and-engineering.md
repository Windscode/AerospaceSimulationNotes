# 可视化与工程工具

## 重点方向

- 三维可视化：UE、Unity、Cesium、Godot。
- 地面站与遥测：Open MCT、Grafana、Python Dash 等。
- 数据处理：Python、Jupyter、Pandas、Matplotlib。
- 工程构建：CMake、Ninja、Docker、GitHub Actions。

## 判断原则

可视化不是仿真的权威源。工程系统里应尽量让核心仿真模块输出权威状态，UE/Godot/Cesium 负责显示、交互和回放。

## 记录重点

- 数据接口格式。
- 坐标系和单位转换。
- 帧率和仿真步长关系。
- 离线回放和实时驱动是否分开。
- 可视化是否影响仿真结果。
