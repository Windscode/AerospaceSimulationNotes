# Maintenance Workflow

## Daily flow

1. 新资料进入 Daily Intake。
2. 判断它属于工具、项目、论文、实验还是行业动态。
3. 只写一句话判断：为什么值得看？
4. 如果有价值，再创建正式条目。
5. 如果需要复现，加入 Reproduction Lab。
6. 如果验证完成，沉淀进 Knowledge Base。

## 每天维护 20 分钟版本

- 5 分钟：收集 3～5 条信息。
- 5 分钟：删除低价值信息。
- 5 分钟：给高价值信息标状态。
- 5 分钟：补一个条目的工程判断。

## 每周维护

- 更新 Tool Stack。
- 更新 Project Radar。
- 把 Daily Intake 中有价值内容转为稳定文档。
- 归档过期内容。

## 不要做的事

- 不要无判断地堆链接。
- 不要复制大段商业文档或论文原文。
- 不要上传破解软件、未授权 PDF、单位内部资料或涉密内容。
