# 轨道与任务分析工具

## 重点工具

- STK：商业任务分析平台，适合复杂场景、覆盖分析和工程交付。
- GMAT：开源任务分析工具，适合轨道转移、优化和验证。
- Orekit：Java 航天动力学库，适合工程系统集成。
- Tudat：偏研究和工程仿真的开源航天动力学工具。

## 评估维度

| 维度 | 记录内容 |
|---|---|
| 建模能力 | 摄动、机动、事件、星历、坐标系 |
| 可编程性 | 脚本、API、批处理能力 |
| 验证价值 | 是否适合作为自研代码的对照基准 |
| 工程集成 | 是否容易嵌入自己的系统 |
| 授权风险 | 商业授权、开源协议、部署限制 |
