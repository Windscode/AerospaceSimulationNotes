# 航天仿真研究库

这个站点不是普通博客，而是个人长期维护的 **航天仿真研究情报与工程知识库**。

核心任务：

1. 跟踪航天仿真相关工程软件、开源项目、论文、技术报告和行业动态。
2. 对工具和项目做工程化评估，而不是只保存链接。
3. 通过复现实验把资料转化为可信结论。
4. 每天维护，但不让内容变成无序收藏夹。

## 内容分层

- **研究情报**：每日新增资料、新闻、论文、工具和项目线索。
- **工程软件栈**：MATLAB、Simulink、Ansys STK、GMAT、Orekit、Tudat、Basilisk、CFD、结构和可视化工具。
- **项目雷达**：开源项目成熟度、许可证、语言、复现状态和工程价值。
- **复现实验室**：编译、运行、验证、误差分析和结论归档。
- **知识库**：稳定长期内容，避免频繁改动。
