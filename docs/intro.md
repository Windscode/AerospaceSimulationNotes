# 航天仿真资料库

这个资料库用于长期整理航天仿真相关资料、开源项目、论文笔记和工程实践。

核心目标不是“收藏更多链接”，而是把资料转化为可复用的判断：

- 这个工具或项目解决什么问题？
- 它能不能编译、能不能运行、能不能复现？
- 它适合学习、论文复现，还是适合工程集成？
- 它和自己的项目有什么关系？

## 推荐使用方式

1. 看到一个资料或项目，先放到对应分类。
2. 用模板记录用途、技术栈、成熟度、风险和下一步动作。
3. 真正跑通过的内容，补充编译环境、依赖版本、运行命令和验证结果。
4. 定期清理低价值链接，保留高价值判断。

## 当前分类

- 学习路线：基础理论和系统学习顺序。
- 工具软件：商业工具、开源工具、工程工具链。
- 开源项目索引：GitHub 项目的可用性评估。
- 论文与资料笔记：论文、教材、技术报告的理解和推导。
- 工程实践：编译、复现、验证、项目集成记录。
