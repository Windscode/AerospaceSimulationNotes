# Tool Stack 总览

工具不是越多越好。每个工具都要明确它在仿真链路里的位置。

| 类别 | 代表工具 | 主要用途 |
|---|---|---|
| 轨道与任务分析 | STK、GMAT、Orekit、Tudat | 轨道设计、任务分析、事件计算 |
| 六自由度动力学 | JSBSim、RocketPy、Basilisk、42 | 飞行器/航天器动力学和控制仿真 |
| 推进 | RocketCEA、CEA 相关工具 | 发动机性能估算、热力计算 |
| 气动 / CFD | SU2、OpenFOAM、OpenVSP | 外形、CFD、气动数据库生成 |
| 可视化与工程 | UE、Cesium、Open MCT、Python | 场景显示、任务回放、遥测界面 |

## 工具记录要求

每个工具至少记录：用途、输入输出、适合阶段、替代工具、学习成本、工程风险。
