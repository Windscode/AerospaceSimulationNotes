# Ansys STK / ODTK / ModelCenter

Ansys STK 是任务分析与系统场景建模的重要商业工具，适合作为轨道、覆盖、链路、星座和任务级可视化的工程参照。

## STK 的站内定位

- Mission analysis benchmark.
- Coverage and constellation analysis.
- Scenario visualization and communication analysis.
- Cross-check tool for custom orbit or mission simulation.

## ODTK 的站内定位

ODTK 关注轨道确定、测量处理、滤波和平滑。它适合作为轨道确定方向的商业参考，不应和普通轨道传播工具混为一谈。

## ModelCenter 的站内定位

ModelCenter 更偏多学科分析和流程集成，可以作为 MDAO、MBSE 和工程流程编排的参考。
