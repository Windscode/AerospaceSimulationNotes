# Project Radar 总览

Project Radar 用于管理开源项目、工具、代码库和资料源的工程价值判断。

它不是收藏夹。每一个项目都要有状态、评级和下一步动作。

## 项目雷达分区

| 分区 | 含义 |
|---|---|
| Watch | 值得关注，但还没验证 |
| Read | 值得阅读源码或文档 |
| Build | 准备本地编译或运行 |
| Reproduce | 准备复现实例或论文结果 |
| Integrate | 可能进入自己的工程系统 |
| Archive | 只做记录，不继续投入 |

## 项目评级

| 评级 | 含义 |
|---|---|
| A | 高价值，值得深入复现或集成 |
| B | 有学习价值，适合阅读和参考 |
| C | 只做索引，暂不投入 |
| D | 不推荐继续投入 |

## 关键原则

不要因为项目 Star 多就判定它有工程价值。真正重要的是：能否编译、能否复现、文档是否清楚、模型边界是否明确、授权是否允许使用。
