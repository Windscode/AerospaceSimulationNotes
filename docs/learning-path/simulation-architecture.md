# 仿真架构

一个成熟的航天仿真系统不能只靠一个好看的三维场景。核心是状态传播、模型边界、验证基准和数据接口。

## 推荐分层

| Layer | Responsibility |
|---|---|
| Simulation Core | 权威状态传播、动力学、事件、模型调度 |
| Model Libraries | 轨道、姿态、推进、气动、环境、传感器 |
| Validation Suite | 基准算例、回归测试、误差统计 |
| Visualization | 三维显示、回放、交互，不作为权威状态源 |
| Knowledge Archive | 记录模型依据、参数来源、复现实验 |

## 关键原则

可视化可以很漂亮，但不能替代仿真权威源。工程系统应让核心仿真输出状态，可视化只负责显示和交互。
