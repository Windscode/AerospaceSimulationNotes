# 轨道与任务分析工具

## 重点工具

- STK：商业任务分析平台，适合复杂场景建模、覆盖分析、可视化和工程交付。
- GMAT：开源任务分析工具，适合轨道转移、优化和任务设计验证。
- Orekit：Java 航天动力学库，适合工程系统集成和服务端计算。
- Tudat：偏研究和工程仿真的开源航天动力学工具。

## 对比维度

| 维度 | 记录内容 |
|---|---|
| 建模能力 | 摄动、机动、事件、星历、坐标系 |
| 可编程性 | 脚本、API、批处理能力 |
| 验证价值 | 是否适合作为自研代码的对照基准 |
| 工程集成 | 是否容易嵌入自己的系统 |
| 授权风险 | 商业授权、开源协议、部署限制 |

## 推荐实践

自研轨道仿真时，不要只相信自己的结果。至少选择 GMAT、Orekit、Tudat 或 STK 中一个作为对照。
