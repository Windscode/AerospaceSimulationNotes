# GNC / ADCS

## 范围

GNC 包括 Guidance、Navigation、Control。ADCS 更偏航天器姿态确定与控制。

## 必须掌握

- 导航：状态估计、测量模型、卡尔曼滤波、传感器误差。
- 制导：目标轨道、转移策略、闭环修正、约束处理。
- 控制：PID、LQR、MPC、滑模控制、执行机构约束。
- 姿态确定：星敏感器、陀螺、太阳敏感器、磁强计组合。
- 姿态控制：三轴稳定、目标指向、太阳帆板指向、动量管理。

## 仿真实现关注点

- 真实系统里导航、制导、控制通常是不同频率。
- 传感器噪声和延迟会显著改变闭环表现。
- 控制器必须考虑执行机构饱和和死区。
- 验证时要区分理想状态反馈和实际测量反馈。
