# 航天仿真研究库

中文默认界面的航天仿真研究门户，用于长期维护工程软件、开源项目、论文资料、每日研究情报和复现实验。

## 本地运行

```bash
npm install
npm run start
```

## 构建

```bash
npm run build
```

## 维护入口

- 数据文件：`src/data/siteContent.js`
- 每日文章：`blog/`
- 长期文档：`docs/`
- 高清视觉图：`static/img/visual/`

## 部署

GitHub Pages 使用 `.github/workflows/deploy.yml` 自动部署。
