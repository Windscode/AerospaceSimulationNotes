# MBSE / MDAO / System Simulation

航天仿真不仅是单一求解器问题，还涉及系统级模型、跨工具联动和数据链路。

## 重点工具

- Ansys ModelCenter：多学科流程集成和优化。
- Simcenter Amesim：一维系统仿真与数字孪生。
- Dymola / Modelica：多域物理系统建模。
- COMSOL Multiphysics：多物理场快速建模。
- Docker / GitHub Actions：可复现工程环境。

## 站内关注

- 是否支持 FMI/FMU。
- 是否能被脚本驱动。
- 是否适合作为离线数据生产工具。
- 是否适合进入 CI 验证流程。
