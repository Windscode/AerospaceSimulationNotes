# Operations 总览

这个目录定义网站的日常维护方法。

日常维护要分清三件事：

1. **发现**：看到新项目、新论文、新工具、新文章。
2. **判断**：它是否值得阅读、复现、长期跟踪。
3. **沉淀**：把有价值内容移动到稳定文档中。

建议每天只做轻量记录，每周做一次整理，每月做一次结构复盘。

## 每天 15 分钟工作流

1. 新增 3-10 条资料线索到 Research Log。
2. 给每条线索标注领域、价值、状态。
3. 选 1 条高价值内容进入 Project Radar 或 Knowledge Base。
4. 记录下一步动作：阅读、编译、复现、放弃。

## 每周 1 次整理

- 清理低价值链接。
- 把短评转为稳定条目。
- 更新项目评级。
- 补充复现实验记录。
