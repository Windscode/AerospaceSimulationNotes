# 轨道力学

## 必须掌握

- 坐标系：ECI、ECEF、LVLH、轨道坐标系。
- 轨道根数：半长轴、偏心率、倾角、升交点赤经、近地点幅角、真近点角。
- 二体运动：开普勒方程、轨道周期、速度方程。
- 摄动：J2、大气阻力、第三体、太阳光压。
- 轨道机动：霍曼转移、平面改变、相位调整、交会。

## 工程实现关注点

- 时间尺度、地球模型、坐标系定义必须统一。
- 数值积分要记录积分器、步长、误差容限和事件检测方式。
- 自研结果要和 GMAT、Orekit、Tudat 或 STK 做对照。

## 最小实验

| Experiment | Goal |
|---|---|
| Two-body closure | 验证二体传播误差 |
| J2 node drift | 验证升交点漂移 |
| Drag decay | 验证低轨衰减趋势 |
| Hohmann transfer | 验证冲量机动计算 |
