# Daily Intake Template

复制下面模板到当天 Research Log 里。

```md
## YYYY-MM-DD Daily Intake

### Item 1

- Title:
- Source:
- Domain: Orbit / GNC / Propulsion / CFD / 6DOF / Tool / Paper / News
- Type: Paper / Tool / Repo / Article / Dataset / Video / Report
- Why it matters:
- Initial value: A / B / C / D
- Action: Read / Build / Reproduce / Archive / Ignore
- Notes:

### End-of-day triage

- Promote to Knowledge Base:
- Add to Project Radar:
- Ignore / archive only:
- Follow-up tomorrow:
```

## 判断标准

- **A**：值得深入阅读或复现。
- **B**：值得保存和后续查看。
- **C**：只做线索记录。
- **D**：暂不投入。
