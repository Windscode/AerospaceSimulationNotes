# Apply Instructions

## Recommended safe workflow

```powershell
git clone https://github.com/Windscode/AerospaceSimulationNotes.git
cd AerospaceSimulationNotes

# Back up current content if needed, then copy all files from this package into the repo root.

npm install
npm run build

git add .
git commit -m "Redesign website as professional aerospace simulation portal"
git push
```

After pushing, open:

```text
https://github.com/Windscode/AerospaceSimulationNotes/actions
```

When the workflow turns green, visit:

```text
https://windscode.github.io/AerospaceSimulationNotes/
```
