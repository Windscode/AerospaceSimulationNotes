# Aerospace Simulation Notes

这个站点不是普通博客，而是一个面向长期维护的航天仿真研究门户。

它的核心任务是把分散的信息转化为可复用的工程判断：

- 一个工具是否值得学？
- 一个开源项目能不能编译、能不能复现？
- 一篇论文的假设条件、公式和工程启发是什么？
- 一个仿真实验是否有基准、是否可重复？
- 每天看到的新资料如何进入长期知识库？

## 三层内容结构

1. **Intelligence Layer**：每日收集、最新动态、快速判断。
2. **Curated Layer**：工具矩阵、项目雷达、论文笔记、复现实验。
3. **Evergreen Layer**：稳定知识库、方法论、长期技术笔记。

## 内容不追求“多”，先追求“可判断”

每个条目都应尽量包含：来源、用途、成熟度、复现状态、工程价值、下一步动作。
