# Project Radar

Project Radar 用于评估开源项目，而不是收藏链接。

## 评价原则

| 维度 | 问题 |
|---|---|
| 领域相关性 | 是否服务航天仿真关键方向？ |
| 成熟度 | 是玩具 demo、研究项目还是工程参考？ |
| 可复现性 | 能否本地构建和运行示例？ |
| 文档质量 | README、API 文档、示例是否清楚？ |
| 授权风险 | 许可证是否允许学习、复用或集成？ |
| 工程价值 | 是否能成为基准、组件或方法参考？ |

## 状态

```text
Discovered / Evaluating / Reproducing / Validated / Archived
```
