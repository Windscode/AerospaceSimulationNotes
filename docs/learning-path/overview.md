# 学习路线总览

航天仿真学习不要从软件按钮开始，而要按“理论基础 → 工具验证 → 工程复现 → 系统集成”的顺序推进。

## 主线

1. 轨道力学：坐标系、轨道根数、摄动、机动、事件。
2. 航天器动力学：姿态描述、刚体动力学、环境力矩、执行机构。
3. GNC / ADCS：估计、制导、控制、传感器和闭环验证。
4. 推进：推力、比冲、质量流率、节流、启动关机、质量特性变化。
5. 气动 / CFD：气动数据库、外形、网格、系数表、再入环境。
6. 仿真架构：状态权威源、步进机制、数据接口、验证基准和可视化分层。

## 学习策略

每个理论点都要对应一个最小复现实验。例如 J2 漂移、霍曼转移、四元数姿态机动、推力曲线积分、气动表插值。
