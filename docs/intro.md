# 航天仿真研究库

这个站点不是普通博客，而是个人长期维护的 **航天仿真研究情报与工程知识库**。它的目标不是堆链接，而是把公开资料、工程软件、开源项目、任务案例和复现实验沉淀成可追溯的研究资产。

<div class="doc-mission-panel">
  <div>
    <span>RESEARCH MODE</span>
    <strong>中文航天仿真研究入口</strong>
    <p>面向中文用户，围绕航天仿真学习、工程工具、公开数据、任务案例和复现实验建立长期维护体系。</p>
  </div>
  <div>
    <span>MAINTENANCE</span>
    <strong>每日维护，但不堆杂物</strong>
    <p>新资料先进入情报流，经过筛选和验证后，再沉淀到知识库、工具矩阵或任务案例。</p>
  </div>
  <div>
    <span>OUTPUT</span>
    <strong>可复现、可追踪、可归档</strong>
    <p>每个结论都尽量关联来源、假设、工具链、数据输入、验证方式和适用边界。</p>
  </div>
</div>

## 核心任务

<div class="doc-step-grid">
  <article>
    <span>01</span>
    <h3>收集研究情报</h3>
    <p>跟踪航天仿真相关工程软件、开源项目、论文、技术报告、任务新闻和行业动态。</p>
  </article>
  <article>
    <span>02</span>
    <h3>做工程化评估</h3>
    <p>对工具、项目和数据源判断工程价值、可复现性、成熟度、许可证和任务适配关系。</p>
  </article>
  <article>
    <span>03</span>
    <h3>组织任务案例</h3>
    <p>用火箭入轨、星座覆盖、月面着陆、再入气动热环境等任务对象承载知识。</p>
  </article>
  <article>
    <span>04</span>
    <h3>沉淀复现实验</h3>
    <p>通过构建、运行、验证、误差分析和结论归档，把资料转化为可信结论。</p>
  </article>
</div>

## 内容分层

<div class="doc-layer-grid">
  <article>
    <h3>研究情报</h3>
    <p>每日新增资料、新闻、论文、工具和项目线索。它是入口，不是最终结论。</p>
  </article>
  <article>
    <h3>工程软件栈</h3>
    <p>MATLAB、Simulink、Ansys STK、GMAT、Orekit、Tudat、Basilisk、CFD、结构和可视化工具。</p>
  </article>
  <article>
    <h3>项目雷达</h3>
    <p>跟踪开源项目成熟度、许可证、语言、复现状态和工程价值，避免只收藏链接。</p>
  </article>
  <article>
    <h3>复现实验室</h3>
    <p>记录编译、运行、验证、误差分析和结论归档，确保研究链路能重新走通。</p>
  </article>
  <article>
    <h3>数据与方法</h3>
    <p>管理公开数据、论文图表、任务报道、TLE、参数估计方法和不确定性说明。</p>
  </article>
  <article>
    <h3>知识库</h3>
    <p>只沉淀稳定长期内容，避免每天新增内容直接污染结构化知识。</p>
  </article>
</div>

## 维护规则

<div class="doc-rule-list">
  <p><strong>先判断来源。</strong> 任何资料进入知识库前，都需要标注来源、时间、可靠性和适用范围。</p>
  <p><strong>先进入情报流。</strong> 每日新增内容不直接写进稳定知识库，先进入研究情报或研究日志。</p>
  <p><strong>先关联任务对象。</strong> 工具、数据、论文和开源项目都要尽量关联到具体任务案例。</p>
  <p><strong>先说明假设。</strong> 公开数据不足时允许估计，但必须区分事实、工程估计和猜测。</p>
  <p><strong>先复现再归档。</strong> 能编译、能运行、能对照、能解释误差，才进入稳定结论。</p>
</div>

## 推荐阅读路径

1. 先看 **研究情报**，了解最近新增资料和线索。
2. 再看 **任务案例**，知道这些知识最终服务哪些仿真对象。
3. 然后看 **工程软件** 和 **项目雷达**，理解工具链和开源项目的作用。
4. 最后看 **数据方法** 与 **复现实验室**，把资料转成可运行、可验证的研究资产。
