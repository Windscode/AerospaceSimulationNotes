# 轨道力学

## 必须掌握

- 坐标系：ECI、ECEF、LVLH、轨道坐标系。
- 轨道根数：半长轴、偏心率、倾角、升交点赤经、近地点幅角、真近点角。
- 二体运动：开普勒方程、轨道周期、速度方程。
- 摄动：J2、大气阻力、第三体摄动、太阳光压。
- 轨道机动：霍曼转移、平面改变、相位调整、交会。

## 仿真实现关注点

- 坐标变换必须统一时间尺度和地球模型。
- 轨道积分要记录积分器、步长、误差容限和事件检测方法。
- 结果应和 GMAT、Orekit、Tudat 或 STK 做交叉验证。

## 可复现实验

- 二体轨道闭合性验证。
- J2 引起的升交点漂移。
- 低轨大气阻力导致的轨道衰减。
- 霍曼转移与有限推力转移对比。
