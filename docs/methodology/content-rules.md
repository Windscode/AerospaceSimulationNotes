# 整理规范

## 资料准入

资料进入仓库前先判断：

1. 是否和航天仿真直接相关。
2. 是否有明确用途。
3. 是否能被未来的自己复用。
4. 是否存在版权、涉密或合规风险。

## 禁止内容

- 涉密资料。
- 单位内部资料。
- 商业软件破解资源。
- 未授权传播的 PDF、模型、数据集。
- 只有链接、没有判断的低价值堆积。

## 推荐写法

每条资料至少回答：

- 它是什么？
- 它解决什么问题？
- 它为什么值得看？
- 它有什么限制？
- 下一步是否要复现或集成？

## 更新节奏

建议每周整理一次：

- 新增高价值项目。
- 清理低价值链接。
- 补充已复现项目的结果。
- 标注过期资料。
