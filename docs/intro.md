# 航天仿真研究库

这个站点不是普通博客，也不是单纯的航天科普站，而是个人长期维护的 **航天仿真研究工作台、工程工具导航、开源数据入口和知识图谱**。目标不是堆链接，而是把公开资料、工程软件、开源项目、飞行器案例、仿真方法和复现实验沉淀成可追溯的研究资产。

<div class="doc-mission-panel">
  <div>
    <span>RESEARCH CONSOLE</span>
    <strong>中文航天仿真研究入口</strong>
    <p>面向中文用户，围绕航天仿真学习、工程工具、公开数据、任务案例和个人项目建立长期维护体系。</p>
  </div>
  <div>
    <span>MAINTENANCE</span>
    <strong>每日维护，但不堆杂物</strong>
    <p>新资料先进入前沿情报，经过筛选和验证后，再沉淀到工具库、开源数据、飞行器档案或知识图谱。</p>
  </div>
  <div>
    <span>OUTPUT</span>
    <strong>可复现、可追踪、可归档</strong>
    <p>每个结论都尽量关联来源、假设、工具链、数据输入、验证方式和适用边界。</p>
  </div>
</div>

## 核心任务

<div class="doc-step-grid">
  <article>
    <span>01</span>
    <h3>收集前沿情报</h3>
    <p>跟踪航天新闻、论文、技术报告、工程软件更新、开源项目动态和公开数据线索。</p>
  </article>
  <article>
    <span>02</span>
    <h3>整理工具资源</h3>
    <p>对工具、项目和数据源判断工程价值、可复现性、成熟度、许可证和任务适配关系。</p>
  </article>
  <article>
    <span>03</span>
    <h3>建立飞行器档案</h3>
    <p>用火箭、卫星、空间站、探测器、再入飞行器等真实对象承载知识和仿真方法。</p>
  </article>
  <article>
    <span>04</span>
    <h3>沉淀复现实验</h3>
    <p>通过构建、运行、验证、误差分析和结论归档，把资料转化为可信结论。</p>
  </article>
</div>

## 内容架构

<div class="doc-layer-grid">
  <article>
    <h3>前沿情报</h3>
    <p>每日新增新闻、论文、工具、项目和数据线索。它是入口，不是最终结论。</p>
  </article>
  <article>
    <h3>飞行器与任务</h3>
    <p>围绕火箭、卫星、空间站、探测器和再入飞行器组织公开参数、图片、子系统和仿真方法。</p>
  </article>
  <article>
    <h3>工具库</h3>
    <p>整理 STK、GMAT、Orekit、Tudat、Basilisk、CFD、结构、可视化和开发工具链。</p>
  </article>
  <article>
    <h3>开源与数据</h3>
    <p>管理开源项目、公开数据库、TLE、论文图表、任务报道、参数估计方法和许可证判断。</p>
  </article>
  <article>
    <h3>知识图谱</h3>
    <p>沉淀轨道、GNC、推进、气动、热控、结构、通信、数值方法和 V&V 等稳定知识。</p>
  </article>
  <article>
    <h3>我的项目</h3>
    <p>记录个人航天仿真项目、工具链实验、复现实验、开发路线和阶段成果。</p>
  </article>
</div>

## 维护规则

<div class="doc-rule-list">
  <p><strong>先判断来源。</strong> 任何资料进入知识库前，都需要标注来源、时间、可靠性和适用范围。</p>
  <p><strong>先进入情报。</strong> 每日新增内容不直接写进稳定知识图谱，先进入前沿情报或研究日志。</p>
  <p><strong>先关联对象。</strong> 工具、数据、论文和开源项目都要尽量关联到具体飞行器、任务或仿真实验。</p>
  <p><strong>先说明假设。</strong> 公开数据不足时允许估计，但必须区分事实、工程估计和猜测。</p>
  <p><strong>先复现再归档。</strong> 能编译、能运行、能对照、能解释误差，才进入稳定结论。</p>
</div>

## 推荐阅读路径

1. 先看 **前沿情报**，了解最近新增资料和线索。
2. 再看 **飞行器与任务**，知道这些知识最终服务哪些仿真对象。
3. 然后看 **工具库** 和 **开源与数据**，理解工具链、开源项目和公开数据的作用。
4. 最后看 **知识图谱** 与 **我的项目**，把资料转成可运行、可验证、可持续维护的研究资产。
