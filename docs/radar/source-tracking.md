# Source Tracking

资料来源要记录清楚，否则几个月后很难判断可信度和时效性。

## 推荐来源类型

- 官方文档。
- 论文与技术报告。
- 开源项目仓库。
- 工具发布说明。
- 航天机构、研究机构、公司技术博客。
- 高质量社区讨论，但要标注不确定性。

## 来源记录格式

| Field | Description |
|---|---|
| Source | 原始来源 |
| Date Checked | 查看日期 |
| Version | 版本或 commit |
| Reliability | High / Medium / Low |
| Notes | 为什么保存 |

## 低可信来源处理

低可信来源不是不能保存，但不能直接进入稳定知识库。先放到 Research Log，等找到更可靠来源再整理。
