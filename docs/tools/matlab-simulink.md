# MATLAB / Simulink / Aerospace Blockset

MATLAB 和 Simulink 是航天仿真、控制设计、数据分析和基于模型设计中的核心工具之一。

## 适合用途

- 控制律设计和验证
- 状态机和任务阶段建模
- 飞行器/航天器动力学原型
- 数据处理和可视化
- 与 C/C++ 或 Python 工具链互补

## 重点模块

- MATLAB
- Simulink
- Stateflow
- Aerospace Blockset
- Simscape
- Control System Toolbox

## 记录重点

不要只记录“会用 MATLAB”。要记录模型结构、输入输出、采样周期、求解器、单位、坐标系和验证基准。
