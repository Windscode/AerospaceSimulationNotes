# Content Pipeline

建议把内容维护成一个流水线，而不是随手乱放。

```text
Discover → Daily Intake → Triage → Radar / Docs / Engineering Log → Monthly Review
```

## 入口规则

| 内容类型 | 初始位置 | 稳定位置 |
|---|---|---|
| 新文章、新资料 | Research Log | Knowledge Base |
| 开源项目 | Project Radar | Projects / Engineering Practice |
| 工具体验 | Research Log | Tool Stack |
| 编译复现 | Engineering Practice | Project Radar 评级更新 |
| 论文阅读 | Research Log | Papers |

## 不要直接放入稳定知识库的内容

- 只看过标题，没判断价值的链接。
- 版权或来源不清楚的资料。
- 明显只是宣传稿、没有技术信息的文章。
- 不能说明用途的 PDF 或项目。
