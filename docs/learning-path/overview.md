# 学习路线总览

航天仿真学习不要只从软件按钮开始。建议按“理论基础 → 工具验证 → 工程复现 → 自己项目集成”的顺序推进。

## 主线

1. 轨道力学：二体问题、轨道根数、坐标系、摄动、轨道机动。
2. 航天器动力学：刚体姿态、四元数、转动惯量、外力矩。
3. GNC / ADCS：导航估计、制导律、姿态控制、轨道控制。
4. 推进：火箭发动机性能、质量流率、比冲、节流、喷管。
5. 气动与再入：大气模型、阻力、升阻特性、热环境、CFD 数据来源。
6. 工程仿真：数值积分、事件检测、坐标转换、单位制、验证基准。

## 学习原则

- 每学一个理论点，都要找一个工具或代码项目复现。
- 不要只看公式，要记录状态量定义、坐标系、单位、适用边界。
- 对任何仿真结果都要问：参考基准是什么？误差从哪里来？
