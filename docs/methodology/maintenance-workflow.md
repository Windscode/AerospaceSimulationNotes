# Maintenance Workflow

网站长期维护建议按三个节奏推进。

## Daily

- 把新发现记录到 Research Log。
- 标注领域、来源、价值和下一步动作。
- 不急着把所有东西放入稳定知识库。

## Weekly

- 从 Research Log 中挑选高价值内容。
- 更新 Project Radar 状态。
- 把已验证内容沉淀到 docs。
- 清理无价值链接。

## Monthly

- 复盘分类是否合理。
- 删除重复、过时、低价值内容。
- 更新首页 featured projects。
- 检查部署、链接和可读性。

## 不要做的事

- 不要把网站变成链接垃圾堆。
- 不要把未经验证的宣传内容写成事实。
- 不要直接上传版权或授权不清的文件。
- 不要让首页承担所有内容维护工作。
