# 航天仿真资料库总览

这个站点的定位不是普通博客，也不是链接收藏夹，而是一个长期维护的航天仿真研究门户。

它服务三个目标：

1. **资料沉淀**：把轨道、姿态、GNC、推进、气动、六自由度、任务分析等方向的资料归档成稳定条目。
2. **项目评估**：对开源项目和工具做工程可用性判断，而不是只看 Star 或 README。
3. **研究记录**：每天发现的新资料先进入 Research Log，再根据价值沉淀到知识库或项目雷达。

## 内容分层

| 层级 | 放什么 | 更新频率 |
|---|---|---|
| Research Log | 每天新发现、短评、资料线索、行业动态 | 高频 |
| Project Radar | 开源项目、工具、代码库的评估和复现状态 | 中频 |
| Knowledge Base | 稳定理论、工具栈、方法论、长期笔记 | 低频但高质量 |
| Engineering Practice | 构建、复现、验证、集成记录 | 按实验更新 |

## 使用原则

每个进入网站的条目都要尽量回答：

- 它是什么？
- 它解决什么问题？
- 它和航天仿真哪一部分相关？
- 它是否能复现或验证？
- 它是否值得后续投入？

如果暂时回答不了，就先放进每日 intake，不要直接塞进稳定知识库。
